# Charan Portfolio

A personal portfolio site built with TanStack Start, React, TypeScript, and Vite.

## Stack

- React 19
- TanStack Start / TanStack Router
- Vite
- Tailwind CSS v4
- Radix UI
- Motion

## Scripts

```bash
npm run dev
npm run build
npm run build:dev
npm run preview
npm run lint
npm run format
```

## Setup

```bash
npm install
npm run dev
```

## Assets

- Hero portrait: `src/assets/heo-portait.png`
- About portrait: `src/assets/about.png`
- Featured image: `src/assets/featured.jpg`

## Notes

- The tab favicon is defined in `public/favicon.svg`.
- The app metadata and routing shell live in `src/routes/__root.tsx`.
